Every setting explained clearly

This page explains not only what each control does, but also which stored data it affects. Changes with potentially destructive consequences require confirmation before they are saved.

Version 0.20.20: This settings guide also covers local placeholder covers, language switching, and the current protections used for cover downloads.

Themes: In Settings → Appearance → Theme, choose Light Mode, Dark Mode, Coral Dark, Coral Light, Blue Light or Blue Dark. The choice also applies to help and the save form. The four new themes show the cover and quick-save action at the top; open Details to edit. Classic themes retain the existing form layout.

Chrome: If a cover needs extra permission, choose Allow cover domain after saving. The new page requests access only to that image domain. Declining leaves your manga saved. Local covers need no permission. Alternatively, in Settings → Interface, enable Automatically load covers from all websites to allow all HTTP/HTTPS websites once. The switch is off by default. Switching off revokes broad access without deleting local covers. Consent is local to this browser and is not synchronized. Firefox is unchanged.

01

Settings sections and saving

Below Settings & backup, choose Appearance, Tag Presets or Technical & Data. Appearance includes themes, language and categories; Tag Presets contains tags and placeholder artwork. Technical & Data includes backups, Sync, browser integration, import, bookmark export and the Import/Error Log and Patchlog tabs. Use Left/Right or Home/End while a section tab is focused. Autosave retains the selected section; switching sections alone does not change data.

Auto-save

Switches and individual selections are stored locally immediately. This includes language, theme, cover visibility, chapter detection, search engine, import mode, and rating scale.

Save Settings

The main button saves every currently visible field together once more. It is an additional deliberate confirmation and does not replace auto-save.

Storage location: The working dataset remains uncompressed in the local Firefox profile so search and editing stay responsive.
02

JSON backup

First click Select backup folder. Chrome opens its built-in directory picker and exposes the folder name only. Firefox on Windows needs the separate local helper: extract its ZIP, run Install.cmd, allow the optional local connection, then select your folder here. No administrator access is required. Verify Create file backup now before enabling daily backups.

Full JSON files include settings, logs and local artwork. Backups run once per local calendar day while the browser is open or on next startup. Retention defaults to 7; invalid input turns red. Only old files recorded in our hidden ownership index are permanently removed after a successful new backup. Keep index files with the backups. Missing/revoked access pauses backups without falling back to Downloads. Firefox shows the full path, Chrome only the folder name. Selection and grants are not synchronized.

Test versions: Removing a temporary Firefox extension is not a regular store update and may remove extension storage. Export a JSON file outside the extension before testing; preferably use a separate test profile. Downloaded backup files remain independent of the add-on. Re-enable automatic file backups after reinstalling or changing profiles.
  • Export: Downloads the collection, settings, logs, and locally stored covers as one portable JSON backup.
  • Import: Restores a backup previously created by Manga Shelf.
  • Before uninstalling: Always create an export because Firefox normally deletes local extension storage when an add-on is removed.
Difference from Firefox Sync: Only the JSON backup includes covers and local logs.
03

Firefox Sync

Enabling or manually running Sync first offers any existing snapshot. Choose Use existing Sync snapshot if local storage is empty. Upload replaces remote data and settings only after additional confirmation. Empty or smaller local collections cannot overwrite it automatically; local changes and conflicts pause automation. Sync is not an independent file backup and does not merge collections.

Automatic synchronization

Transfers manga metadata and settings between signed-in desktop Firefox profiles. Firefox requests optional data permissions on first activation. Nothing is transferred without consent.

Compressed cache

A gzip-compressed Sync copy remains prepared locally. Sync Now uploads this copy without recompressing unchanged data.

Load from Sync

After confirmation, replaces the local manga state with the complete remote snapshot. Existing local covers for matching manga are preserved.

Status display

Manga count, transport chunks, storage use, and compression ratio show how efficiently the quota is used.

Privacy: Local use does not require data transfer. Sync uses the declared optional data types only after Firefox consent. Covers, favicons, cookies, logs, bookmark IDs, and folder paths remain on the current device.
04

Firefox integration, shortcut, and reading limit

Toolbar icon

Opens the save form in the current website tab. On protected Firefox pages, it opens the collection instead.

Keyboard shortcut

Firefox requires Ctrl or Alt as the primary modifier. Shift may be added. Already assigned combinations must be replaced.

Reading limit

Sets the maximum number of entries in Currently Reading. It cannot be reduced below the current occupancy.

05

Bookmark import

Default category

Determines where new entries from the tab form, manual form, and Firefox import are initially placed.

Select folders

Imports selected folders only. Choose an initial rating and target category above the selection; individual folders can override them. Manual and keyword selections use the values above. Active rating rules take priority over the target category.

Keyword

Imports bookmarks whose title or address contains the configured term, such as “Chapter”.

Manual selection

Shows every website bookmark for individual selection. The import button in the main header can be hidden completely.

06

Write the collection back to Firefox bookmarks

The Back to Firefox section creates a Manga-Regal root under Other Bookmarks. It contains one subfolder for every real category, including custom categories.

Tool-created entries too

Every manga in the collection is exported, regardless of whether it originated from Firefox or was saved directly through Manga Shelf.

Bookmark data only

Each Firefox bookmark contains only the manga title and current URL. Ratings, tags, covers, chapter metadata, and local logs are excluded.

Safe updates

A repeated export replaces only the folder whose device ID was stored by Manga Shelf. Unrelated folders with the same name remain untouched.

No duplicate aggregate view

All is only an aggregate view. Each manga appears exactly once in its category folder and is already accessible through the root folder.

Process: Manga Shelf builds a complete new bookmark tree first. Only after every bookmark succeeds does it replace a previous managed export.
07

Appearance, covers, and rating scale

  • Language: Switches the interface and injected tab form between German and English. The help opens the matching language page; the add-on description, toolbar tooltip, and shortcut text follow Firefox's locale.
  • Theme: Choose one of six themes instead of toggling light/dark. Changes are saved immediately and applied to the collection, settings, popup and help.
  • Table covers: Shows locally stored images in table rows. Images still load only when visible.
  • Placeholder covers: Four bundled artworks add variety to entries without a cover. Assign tags to a specific artwork or keep automatic selection. Every artwork can be replaced, and the complete placeholder feature can be disabled without deleting assignments.
  • Rating scale: New installations use five stars. Ten stars remain optional.
  • Startup dialog: Enables or disables the welcome dialog. Completing it once prevents it from being forced again.
  • Detect chapters from URLs: Globally enables or disables automatic URL-number analysis. Turning it off clears automatically detected values but preserves manually maintained chapters. The save form can additionally disable detection permanently for one manga.
  • Offer re-read option: Shows the button for creating a second internally linked reading progress in the update dialog. The proposed target remains editable.
  • Automatically tag re-reads: Adds the visible green Re-Read tag to newly created re-reads. Disabling it does not remove the internal link used for chapter targeting.
From 10 to 5 stars: If ratings above five exist, a confirmation dialog appears first. After confirmation, only those ratings are capped at five; values from one through five remain unchanged.
08

Search engines for replacement sources

Find New Source uses the manga title and current chapter. Select the Firefox default, an installed provider, one of six presets, or a custom search URL.

Custom search URL: It must start with https:// or http:// and contain {query}, for example https://example.com/search?q={query}.
09

Manage categories

Name

Standard categories can be renamed. An empty field or reset button restores the translated default name.

View

Every category has its own table or card layout. The selection is retained for future visits.

Order and visibility

Drag a row by its handle, use the arrows, or drag tabs directly in the top navigation. The visibility button before the layout dropdown also hides built-in categories. No manga are deleted; hidden categories remain available for assignments. At least one tab must stay visible.

Categories by rating

Open Assign ratings beside Visible in the desired category row. Select one or more exact star scores. Each score has one target category; selecting it elsewhere replaces its previous assignment. Confirm to move matching existing manga. Future rules run on new entries and changed ratings, including imports. Manual category changes survive until the next rating change; chapter-only updates do not reroute entries. Removing a rule does not undo earlier moves. If the Reading limit is exceeded, the complete operation is cancelled without partial changes. Rules above five stars are removed when switching to the five-star scale.

Custom categories

Additional categories can be created and removed. Manga from a removed category are safely moved to Active.

All is an aggregate view rather than a status that can be assigned to a manga.

10

Tag presets

The checkboxes control which frequent tags appear in the Edit Tags popup. Re-Read is directly available as a default preset. Custom presets can be added, while spelling mistakes can be corrected by removing and recreating a preset.

Under Placeholder Covers by Tag, drag tags onto one of the four artworks. Replace Image changes a fixed slot to a custom local image; Default Image restores only that slot. The slider hides every placeholder but retains artwork and assignments for later use.

Storage: Custom placeholder images are included in JSON backups but excluded from Firefox Sync because of their size.
Important: Removing or disabling a preset never removes that tag from manga already using it.
11

Import/error log and patch notes

Import & error log

Shows local events, warnings, and errors. Filter by level or text and clear the log when needed. Logs are not transferred through Firefox Sync.

Patch notes

Shows a concise summary of features and fixes in the currently installed version. The complete history is maintained in the linked GitHub changelog.
