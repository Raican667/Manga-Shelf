Local Firefox extension

Your Manga Shelf, step by step

This guide covers every feature of the extension. Unless Firefox Sync is enabled, your collection, ratings, tags, and covers remain entirely in the local Firefox profile. Manga Shelf does not operate its own server.

1Open a manga page in Firefox
2Click the Manga Shelf icon
3Review the data and save
Version 0.20.11: This guide describes the current interface, including localized help, automatic chapter and cover switches, and custom placeholder covers.

Chrome: If a cover needs extra permission, choose Allow cover domain after saving. The new page requests access only to that image domain. Declining leaves your manga saved. Local covers need no permission. Alternatively, in Settings → Interface, enable Automatically load covers from all websites to allow all HTTP/HTTPS websites once. The switch is off by default. Switching off revokes broad access without deleting local covers. Consent is local to this browser and is not synchronized. Firefox is unchanged.

01

Save a manga from the current tab

Click the Manga Shelf icon in the Firefox toolbar. The form appears in the current website tab. Within the form, click its icon or title to open the collection. The Open Collection button is also available.

Detected automatically

Title, website address, description, current chapter, and an available cover are filled in whenever possible.

Before saving

You can correct or add the title, chapter, category, rating, and tags. New installations use five stars by default; ten stars remain available in Settings.

Per-manga automation

The small switch after the chapter field disables automatic detection only for this manga. The choice persists through future updates, while manual input remains available.

Confirmation

After saving, the form reports whether both manga and cover were stored locally or whether only the cover could not be loaded.

Tip: If the icon is visible only in the Extensions menu, open the puzzle-piece menu and pin Manga Shelf to the toolbar.
02

Update a chapter you have read

When you open and save another chapter of the same manga, Manga Shelf compares the title with existing reading progress—not only the current source URL. A dialog suggests the best target, lets you change it, or creates a linked re-read.

  • Update an existing entry: The URL and chapter normally change, while rating, tags, category, and local cover remain. If chapter automation is red for this manga, only the Continue Reading URL changes and the stored chapter stays frozen.
  • Primary progress or re-read: A chapter at or below the primary progress suggests an existing re-read. A higher chapter suggests the primary entry. You can always change the target from the dropdown. The connection remains when a website changes its URL.
  • Create as a new re-read: Creates a separate reading progress linked internally to the primary one. It can optionally receive the green Re-Read tag.
  • Save separately: Deliberately creates another independent entry.
  • Cover: A chapter update downloads a cover only when the entry has no local cover yet.
03

Use the collection

Continue reading

Opens the stored chapter URL. Find New Source searches by title and chapter if the original website has closed.

Filter & sort

Search by title, website, or tag. Filter by every value in the five- or ten-star scale. Column headers sort text alphabetically and numeric values highest first.

Edit directly

Chapter, stars, tags, and status can be changed in the overview. The pencil opens the full entry; the trash icon removes it after confirmation.

Table or cards

Every category can have its own layout. Covers can additionally be hidden from table rows.

04

Categories, custom names, and reading limit

The default views are Currently Reading, Active, On Hold, Dropped, Completed, and All. Their visible names can be changed, and additional categories can be created.

Currently Reading

This area is intended for titles you are actively reading. Its occupancy is displayed, for example, as 3/5. Once the configurable limit is reached, one title must be moved elsewhere first.

Default for new manga

Choose the initial category for entries created from the tab form, manual form, and bookmark import.

05

Import and recreate Firefox bookmarks

The import uses bookmark information provided by Firefox. When chapter detection is enabled, matching progress is added from the URL; otherwise the optional field remains open for manual input.

Select folders

Import only selected folders and optionally give every item in a folder the same rating.

Keyword

Import bookmarks whose title or address contains a term such as “Chapter”.

Manual selection

Select individual bookmarks from every Firefox folder.

The import button in the page header can be hidden completely in Settings.

Back to Firefox: Settings can recreate the complete collection under a Manga-Regal root folder with one subfolder per category. This includes entries that were never imported from Firefox. Only title and current URL are exported.
06

How covers are stored and loaded locally

  • When first saving an entry, the extension downloads the detected cover and stores it separately from the main dataset.
  • Collection images load only when their row or card enters the visible area, so the entire library is not rendered at once.
  • A normal chapter update preserves the existing cover. The small control after the cover address can permanently disable automatic cover detection for one manga.
  • Without a custom cover, Manga Shelf uses one of four local artworks. It selects by tag automatically, or you can assign a fixed artwork to each tag with drag and drop.
  • Each placeholder slot can be replaced with a custom JPG, PNG, or WebP image. The Show Placeholder Covers switch hides every replacement image without deleting artwork or mappings.
  • For Cloudflare-protected pages, Manga Shelf can reuse the image visible in the active tab. Cookies are never read, stored, or synchronized. Covers remain protected inside the Firefox profile, and JSON backups include them.
07

Settings

Appearance

Use switches for dark/light and German/English. Each category has its own table/card setting. Table covers are enabled for new installations.

Tags

Enable frequent tags, create custom presets, or remove misspelled presets. Tags already assigned to manga remain untouched.

Search engine

Use the Firefox default, an installed provider, one of six presets, or a custom URL containing {query}.

First launch

A brief starter dialog appears once after installation with the three essential steps and a link to this guide.

Categories & stars

Edit category name, layout, and order together. Drag rows or use arrow buttons. Reducing ten stars to five requires confirmation and caps only values above five.

Keyboard shortcut

Firefox requires Ctrl or Alt as the primary modifier; Shift may be added. Choose another combination if it is already assigned.

Saving: Individual changes save automatically. The additional Save Settings button saves all visible settings together once more.

08

Transfer the collection with Firefox Sync

Under Settings → Firefox Sync, you can enable synchronization, run it immediately, or load an existing Sync snapshot. Firefox must be signed in to a Mozilla account with add-on synchronization enabled. On first activation, Firefox displays its native optional-data consent dialog.

What is synchronized

Title, URL, chapter, rating, tags, category, and settings are gzip-compressed as one snapshot. The prepared local copy is refreshed after changes and uploaded in size-limited transport chunks.

What remains local

Covers, favicons, logs, Firefox bookmark IDs, and folder paths are excluded. Loading a Sync snapshot preserves matching local covers already present on the device.

Storage limit: Firefox provides approximately 100 KB of Sync storage per extension. Settings show manga count, chunks, used storage, and compression ratio. Use JSON export for a complete backup including covers.
09

Backup and logs

JSON backup

Download collection, settings, logs, and local covers in one portable file. Import restores a previously created Manga Shelf backup.

Import & error log

The local log shows imports, warnings, and errors. It can be filtered by level and text or cleared completely.

Important: Create a JSON backup before removing the extension. Firefox normally deletes an extension's local storage during uninstall.
10

Troubleshooting

A cover is not displayed

Open the entry with the pencil and check its cover address. Some websites or Cloudflare block direct extension requests. Save another direct image address or open the manga page in the active tab so the visible image can be reused. Placeholder covers are available when no own image can be stored.

The icon or popup is missing

Open about:debugging#/runtime/this-firefox and click Reload for Manga Shelf. If the icon is only in the Extensions menu, pin it through the puzzle-piece menu. On internal Firefox pages, the toolbar click opens the collection instead.

The keyboard shortcut cannot be saved

Use Ctrl or Alt plus another key, for example Alt + Shift + M. Shift+D alone is invalid in Firefox. Choose another combination if Firefox reports a conflict.

Currently Reading rejects another manga

The displayed limit has been reached. Move one title to Active, On Hold, Dropped, or Completed, or increase the limit in Settings.

Continue Reading opens a closed website

Use Find New Source directly below it. Manga Shelf opens a search containing the title and stored chapter.

Where is my data on Windows?

It is stored in the extension storage inside the local Firefox profile. Use JSON backup when you need a normal portable Windows file.
