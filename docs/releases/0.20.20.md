## English

### Combined release notes: 0.20.15–0.20.20

This release combines the changes developed since 0.20.15 into one update.

- **Organized settings:** Appearance, Tag Presets and Technical & Data tabs. Backup, Sync, browser integration, bookmark export and both logs are grouped together. Keyboard navigation and German/English labels are supported.
- **Category controls:** Hide built-in or custom categories without deleting manga, reorder tabs in navigation or settings, and select table/card layout per category. At least one category remains visible.
- **Rating-based routing:** Assign exact star scores directly in each category row. Confirmation moves existing matches; new entries and changed ratings follow the rules. Manual category changes survive chapter-only updates. Reading limits reject overfull operations without partial changes.
- **Bookmark imports:** Choose an initial rating and target category for folder, manual and keyword imports. Folders can override shared choices; active rating rules take priority.
- **Independent file backups:** Opt-in daily JSON files include manga, settings, logs, local covers and custom placeholder artwork. Missed days are handled on next startup while the browser runs. A day counts as successful only after the complete file and ownership index are written.
- **Backup retention:** Editable positive count, default 7, internally limited to 365. Invalid values turn red and are not saved. After a successful backup, only the oldest matching files created by this extension above the limit are permanently deleted. Failed file writes do not trigger cleanup. Only safe filenames in the chosen folder's owner-specific index are managed.
- **Sync loss protection:** Empty, smaller or not-yet-connected local collections cannot automatically replace an existing Sync snapshot. Connecting or syncing manually offers a snapshot choice; replacing remote data requires additional confirmation. Automatic restore pauses for smaller remote collections or unsynced local edits. Snapshot choices are revision-bound and uploads no longer clear every active Sync key first.
- **Popup compatibility:** Shadow DOM prevents website CSS from hiding or displacing the save form. Packaged styles also work with strict page style policies. All six themes, tags, ten stars and narrow screens were tested.
- **Persistence fixes from 0.20.15:** Explicit per-category table views and intentionally empty import keywords are retained. Added regression coverage for settings, categories, progress and separate local image keys across upgrades/restarts.

- **Firefox backup error fixed:** automatic backups no longer use data:-URLs with downloads.download. Missing or revoked folder access pauses backup instead of silently using Downloads. Legacy error messages no longer display embedded JSON content.

### Important limitations

- **Backup folder selection is now included:** use Settings → Technical & Data → Select backup folder. Chrome uses its own picker; Firefox on Windows requires the attached backup-helper ZIP (extract, run Install.cmd once, then select the folder). The helper is unsigned and opt-in; source is included. No administrator access or permanent service. Other Firefox platforms can still use manual JSON export.
- Sync is not an independent backup or a conflict-free multi-device merge. Covers stay local and are included in JSON files, not Sync.
- Removing a temporary Firefox extension can remove its local storage; it is not equivalent to a regular signed-store update. Already deleted data cannot be recovered by installing this update. Export a JSON backup first and use a separate test profile.
- Tests use isolated data and browser API simulations plus real Chromium UI checks; they do not replace a signed Firefox/Chrome store-upgrade test.

## Deutsch

### Zusammengefasste Versionshinweise: 0.20.15–0.20.20

Dieses Release bündelt die seit 0.20.15 entwickelten Änderungen in einem Update.

- **Übersichtliche Einstellungen:** Reiter für Darstellung, Tag-Vorauswahl und Technik & Daten. Sicherung, Sync, Browser-Integration, Lesezeichenexport und beide Protokolle sind zusammengefasst. Tastaturbedienung und deutsche/englische Beschriftungen sind enthalten.
- **Kategorien verwalten:** Standard- und eigene Kategorien ausblenden, ohne Manga zu löschen; Reiter direkt oben oder in den Einstellungen verschieben; Tabellen-/Kachelansicht je Kategorie wählen. Mindestens eine Kategorie bleibt sichtbar.
- **Zuordnung nach Bewertung:** Exakte Sternebewertungen direkt in der Kategoriezeile zuweisen. Nach Bestätigung werden vorhandene Treffer verschoben; neue Einträge und geänderte Bewertungen folgen den Regeln. Manuelle Kategorieänderungen bleiben bei reinen Kapitelupdates erhalten. Überschrittene Leselimits brechen Aktionen ohne Teiländerungen ab.
- **Lesezeichen-Import:** Startbewertung und Zielkategorie bei Ordner-, Einzel- und Schlüsselwort-Import wählen. Eigene Werte je Ordner sind möglich; aktive Bewertungsregeln haben Vorrang.
- **Unabhängige Dateisicherung:** Optionale tägliche JSON-Dateien enthalten Manga, Einstellungen, Protokolle, lokale Cover und eigene Platzhalterbilder. Nachholen beim nächsten Browserstart; erst vollständig geschriebene Datei und Eigentumsindex zählen als Erfolg.
- **Aufbewahrung:** Frei eingebbare positive Anzahl, Vorgabe 7, intern auf 365 begrenzt. Ungültige Werte werden rot markiert und nicht gespeichert. Erst nach erfolgreicher Sicherung werden die ältesten passenden eigenen Dateien über dem Limit dauerhaft gelöscht. Fehlgeschlagene Schreibvorgänge lösen keine Bereinigung aus. Verwaltet werden nur sichere, im Eigentumsindex des Zielordners verzeichnete Dateien.
- **Sync-Verlustschutz:** Leere, kleinere oder noch nicht mit dem aktuellen Stand verbundene lokale Sammlungen ersetzen einen vorhandenen Sync-Stand nicht automatisch. Beim Verbinden oder manuellen Synchronisieren wird der Stand gewählt; Überschreiben verlangt zusätzliche Bestätigung. Automatischer Restore hält bei kleineren entfernten Sammlungen oder ungesicherten lokalen Änderungen an. Entscheidungen gelten für die geprüfte Revision; Uploads löschen nicht mehr zuerst sämtliche aktiven Sync-Schlüssel.
- **Pop-up-Kompatibilität:** Shadow DOM verhindert, dass Webseiten-CSS das Speicherformular ausblendet oder verschiebt. Mitgelieferte Styles funktionieren auch bei strengen Seitenrichtlinien. Alle sechs Themes, Tags, zehn Sterne und schmale Ansichten wurden getestet.
- **Speicherfehler aus 0.20.15 behoben:** Explizite Tabellenansichten je Kategorie und bewusst leere Import-Schlüsselwörter bleiben erhalten. Neue Regressionstests prüfen Einstellungen, Kategorien, Lesestände und separate lokale Bildschlüssel bei Updates/Neustarts.

- **Firefox-Sicherungsfehler behoben:** Automatische Sicherungen verwenden keine data:-URLs mit downloads.download mehr. Fehlende Ordnerrechte halten die Sicherung an, statt auf Downloads zurückzufallen. Alte Fehlermeldungen zeigen keinen eingebetteten JSON-Inhalt mehr an.

### Wichtige Einschränkungen

- **Zielordnerwahl ist jetzt enthalten:** Einstellungen → Technik & Daten → Zielordner auswählen. Chrome nutzt seinen Ordnerdialog. Firefox unter Windows benötigt das beiliegende Helfer-ZIP: entpacken, Install.cmd einmal ausführen, anschließend Ordner wählen. Der Helfer ist nicht digital signiert, optional und mit Quelltext enthalten; keine Administratorrechte oder permanenter Dienst. Andere Firefox-Plattformen können weiterhin manuell JSON exportieren.
- Sync ist keine unabhängige Sicherung und kein konfliktfreier Mehrgeräte-Merge. Cover bleiben lokal und sind Teil der JSON-Dateien, nicht des Syncs.
- Entfernen einer temporären Firefox-Erweiterung kann den lokalen Speicher entfernen und entspricht keinem regulären signierten Store-Update. Bereits gelöschte Daten stellt dieses Update nicht wieder her. Vorher JSON exportieren und ein separates Testprofil verwenden.
- Getestet wurde mit isolierten Daten, simulierten Browser-APIs und echten Chromium-Oberflächentests; dies ersetzt keinen signierten Firefox-/Chrome-Store-Upgrade-Test.
