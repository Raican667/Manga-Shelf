# Manga Shelf 0.20.21

## English

- Automatic daily JSON backups now use **MangaShelf/Backups inside your browser download folder**, in Firefox and Chrome. No external helper or folder-selection setup is needed. Enable daily backup and allow the optional download permission.
- Default retention is **7**, with an editable count. Only recorded own old backups are removed after a new complete download. Clearing download history or uninstalling the extension can prevent cleanup of old files; remove those manually.
- Firefox uses Blob URLs to fix the JSON data-URL access-denied error. Chrome service workers use a compatible UTF-8 download path. Full JSON includes collection, settings, logs and local covers.
- Removed the native-messaging helper, installer/build scripts, directory picker, obsolete integration actions and helper release asset. The helper asset from 0.20.20 has also been withdrawn.
- English/German help, settings and patch notes updated. Existing collection, cover storage, Sync and preferences are retained. Daily backup remains opt-in; if previously enabled, it now uses the download folder.
- Tested scheduling, both download URL paths, Unicode/full JSON, permission denial, interrupted downloads, retention and file ownership. Browser store publication remains separate from this GitHub release.

## Deutsch

- Automatische tägliche JSON-Sicherungen liegen bei Firefox und Chrome unter **MangaShelf/Backups im Downloadordner des Browsers**. Kein Zusatzprogramm und keine Zielordner-Einrichtung nötig. Tägliche Sicherung einschalten und die optionale Download-Berechtigung erlauben.
- Aufbewahrung mit Standardwert **7**, weiterhin frei einstellbar. Nur eigene protokollierte alte Sicherungen werden nach vollständig neuer Datei gelöscht. Nach Leeren des Downloadverlaufs oder Entfernen der Erweiterung können alte Dateien nicht mehr zugeordnet werden; diese manuell entfernen.
- Firefox verwendet Blob-URLs gegen den Fehler bei JSON-Datenadressen. Chrome-Service-Worker nutzen einen kompatiblen UTF-8-Downloadweg. Vollständiges JSON mit Sammlung, Einstellungen, Protokollen und lokalen Covern.
- Native-Messaging-Helfer, Installer-/Buildskripte, Ordnerauswahl, alte Integrationsaktionen und Helfer-Release-Asset entfernt. Auch der Helfer-Download von 0.20.20 wurde zurückgezogen.
- Deutsche/englische Hilfe, Einstellungen und Patchnotes aktualisiert. Sammlung, Coverspeicher, Sync und Einstellungen bleiben erhalten. Tägliche Sicherung bleibt optional; bei vorheriger Aktivierung wird nun der Downloadordner genutzt.
- Planung, beide Downloadwege, Unicode/vollständiges JSON, verweigerte Berechtigung, Downloadabbruch, Aufbewahrung und Dateibesitzer geprüft. Store-Veröffentlichung erfolgt separat vom GitHub-Release.
